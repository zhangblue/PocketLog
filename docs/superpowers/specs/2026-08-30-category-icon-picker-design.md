# 分类固定图标选择器设计

## 目标

在“分类与账户标签”页面创建分类时，让用户从固定常用图标中选择分类图标，并将选择的
Emoji 与分类一起持久化。

## 交互

- 创建分类表单在名称和类型字段之后提供“分类图标”按钮网格。
- 默认选中 `🏷️`。点击任一图标即更新当前选择；保存请求携带该 Emoji。
- 图标网格下方提供“自定义 Emoji”文本输入。用户输入非空内容后，修剪首尾空白并将其
  作为当前选择；再次点击固定图标会覆盖自定义选择。
- 切换分类类型后显示该类型对应图标。已选固定图标不属于新类型时重置为 `🏷️`；用户
  手动输入的自定义 Emoji 不因类型切换而改变。
- 图标按钮显示图标与文字标签，使用 `aria-pressed` 表示选择状态，并支持 Tab、Enter
  与 Space 键操作。
- 已有分类和历史交易不被修改，继续显示其持久化的图标。

## 数据与范围

前端现有的创建分类动作与后端 API 已支持 `emoji` 字段。本次只为创建表单补齐固定选择、
自定义 Emoji 输入和传值，不改变数据库 schema、API 契约或旧分类数据。自定义输入沿用
后端既有的 1 至 16 个 Unicode 字符校验；服务端拒绝时保留用户输入并显示现有可恢复错误。

## 验收

- 支出网格包含“通讯”“网络”和“其他”；收入网格包含“其他”。
- 选择图标后创建请求携带对应 Emoji；未选择时携带 `🏷️`。
- 自定义 Emoji 输入会覆盖当前选择，固定图标点击会覆盖自定义输入。
- 类型切换不会让不属于当前类型的固定图标保留为选中状态，但保留自定义 Emoji。
- 图标选择支持键盘和可访问状态反馈。
