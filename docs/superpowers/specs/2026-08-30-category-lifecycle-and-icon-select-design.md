# 分类生命周期与图标下拉修订设计

## 目标

将固定分类图标下拉精简为仅 Emoji，并使分类的启用、停用、删除和迁移操作与后端约束一致。

## 图标下拉

- 固定图标使用原生下拉框，选项只显示 Emoji，不显示文字名称。
- 自定义 Emoji 输入保留；非空自定义输入优先于下拉选择。

## 分类生命周期

- 启用分类仅显示“停用”，不显示直接删除。
- 停用且没有历史交易的分类显示“启用”和“删除”。
- 停用且存在历史交易的分类显示“启用”和“迁移并删除”。
- 启用操作调用已有标签激活 API，并在成功后恢复该分类用于新增记账。
- 删除请求被服务端以“仍启用”拒绝时，确认对话框保持打开并提示“请先停用该分类后再删除”。

## 验收

- 下拉选项仅含 Emoji 文本。
- 启用、停用、删除、迁移按钮组合随分类状态和历史引用正确变化。
- 停用分类可以重新启用；启用成功后列表与新记账可选项同步更新。
- 删除失败不关闭确认对话框，并显示可恢复中文提示。
