# 总览支出趋势折线图设计

## 目标

调整总览菜单的“支出趋势”图表：横轴展示自然日日期但在日期较多时均匀减少标签，纵轴展示金额，鼠标或键盘聚焦数据点时显示精确金额。

## 图表与数据

- 使用总览 API 返回的每日支出趋势数据，不重新从可能分页的交易列表计算。
- 所有日期数据点继续绘制，不能因隐藏横轴文字而丢失趋势数据。
- 横轴标签只显示日期部分（`MM-DD`），最多显示 6 个，按数据顺序均匀取样并始终保留首尾日期。
- 纵轴根据当前数据最大金额动态生成 4 个金额刻度，包含 `¥0`；最大值向上取整到易读量级，空数据时保持安全的零值刻度。
- 折线节点位置按完整数据数组等距计算，金额按纵轴最大值映射到图表高度。

## 交互与无障碍

- 每个数据点具备可聚焦、可键盘操作的语义元素，并提供包含完整日期和金额的 `aria-label`。
- 鼠标移入或键盘聚焦节点时显示 Tooltip，格式为“`YYYY-MM-DD · ¥金额`”；移出或失焦时隐藏。
- 图表保留标题、描述和可见文字摘要；摘要列出可追溯的日期与金额。
- 不依赖颜色传达金额，Tooltip 和纵轴文字始终提供数值。

## 空态与兼容性

- 总览首次使用和无交易空态沿用现有页面逻辑，不渲染无意义零值图表。
- API 加载错误沿用现有 AsyncPanel 标题与重试行为。
- 不改变总览汇总指标、分类构成、洞察或下钻数据。

## 测试

- 验证横轴显示 `MM-DD` 且日期较多时最多 6 个并保留首尾。
- 验证 4 个金额纵轴刻度、`¥0` 和动态最大值。
- 验证悬停与键盘聚焦显示精确金额，移出/失焦隐藏。
- 验证完整数据摘要仍包含所有日期和金额，以及空态不渲染图表。
- 执行前端定向测试、全量检查和生产构建。

## 范围外

- 不改变后端 API、数据库 schema、统计口径或总览其他模块。
- 不引入第三方图表库；继续使用现有 SVG 组件。
